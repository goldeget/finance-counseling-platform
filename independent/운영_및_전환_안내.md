# 금융상담 플랫폼 독립 운영 안내

작성 기준: 2026-11-12 한국시간. 이 문서는 시험과 전환 준비 상태를 기록하며, 출시 완료 확인서가 아닙니다.

## 현재 구성

1. 고객이 접속하는 `loan.climekr.com`은 현재 기존 Sites 서비스입니다. 독립 Cloudflare Worker로 아직 전환하지 않았습니다.
2. 소스는 비공개 GitHub 저장소 `goldeget/finance-counseling-platform`의 `main` 브랜치에 있습니다. `independent-staging` 브랜치에는 시험 구현 이력이 있습니다. 저장소 접근과 자동 배포 연결은 별개입니다. Cloudflare GitHub 앱에 저장소 접근을 추가했지만 Workers Builds 자동 배포 설정과 전용 권한 토큰은 아직 완성되지 않았습니다.
3. 독립 시험용 Worker와 운영용 후보 Worker가 따로 있습니다. 운영용 후보에는 아직 고객 도메인 경로가 붙어 있지 않습니다. 원본 사이트를 대체하기 전에 최종 동기화와 실제 도메인 시험이 필요합니다.
4. 상담 접수는 암호화하여 전용 Cloudflare D1에, 후기는 별도 Supabase 프로젝트 `finance-counseling-reviews`에 저장하는 구성입니다. 다른 유심 사이트의 저장소와 구분했습니다.
5. 관리자 접근은 Cloudflare Access의 이메일 일회용 인증과 서버의 서명 검증을 함께 사용합니다. 시험 관리자 화면에서 로그인, 후기 등록 및 삭제를 확인했습니다. 후기 복사 후에는 운영용 인증만 후기 변경에 허용하도록 바꾸었으므로 시험 관리자에서 후기 등록·삭제는 더 이상 동작하지 않습니다. 운영 관리자 도메인에서의 최종 로그인과 실제 권한은 전환 전에 다시 확인해야 합니다.

## 자료 이전과 개인정보 보관

- 최초 복사 시점에 기존 사이트에서 후기 108,250건과 상담 접수 11건을 확인했습니다. 접수는 암호화하여 복사했고, 복사된 11건의 암호화 필드 일치를 검증했습니다. 후기 108,250건도 번호, 작성자, 출처, 본문, 별점 및 날짜를 하나씩 대조해 불일치가 없었습니다. 원본이 계속 운영되고 있으므로 이 숫자는 전환 직전 숫자를 뜻하지 않습니다.
- 독립 Worker에는 접수 시점부터 1년이 지난 상담 접수를 정기 삭제하는 기능이 있습니다. 매일 한국시간 03:00 실행 일정이 설정되어 있으며, 시험 환경에서 오래된 시험 접수만 삭제되는 것을 확인했습니다. 운영 후보의 실제 일정 실행, 실패 감시와 복구 절차는 전환 전에 확인해야 합니다.
- D1의 시점 복구 자료와 이전 작업용 F 드라이브 암호화 복사본에는 별도의 보존 기간과 삭제 절차가 필요합니다. 이전 작업용 복사본을 영구 보관하면 본 저장소의 삭제만으로 모든 복사본이 삭제되는 것은 아닙니다. 전환 검증 후 해당 임시 복사본을 정리하고, 이후 만들어지는 백업에도 보관기간과 파기 절차를 적용해야 합니다.
- 암호화 키는 Cloudflare의 Worker 비밀 설정과 비공개 GitHub 저장소의 Actions 비밀 설정에 보관하며, 이 PC의 현재 Windows 계정에서만 복원 가능한 보호 사본도 F 드라이브에 있습니다. GitHub 비밀은 설정 후 화면에서 다시 읽을 수 없고 복구 배포 절차는 아직 시험하지 않았습니다. PC 사본도 다른 PC나 Windows 계정으로 옮겨 복구할 수 있다는 뜻이 아닙니다. 기기 분실에 대비한 별도의 안전한 키 보관 및 복구 훈련이 필요합니다. 키나 고객 자료를 GitHub 소스에 올리거나 채팅으로 공유하지 마세요.

## 운영 전환 전 남은 작업

1. 기존 사이트의 신규 접수와 후기 변경을 짧은 전환 구간에 통제하고, 그 시점의 모든 변경·삭제를 새 저장소에 반영해 건수와 내용을 대조합니다. 단순한 최초 복사만으로 전환하면 그 이후의 고객 접수가 누락될 수 있습니다.
2. 운영 관리자 도메인과 후기 관리자 함수가 모두 운영용 Cloudflare Access 설정을 검증하는지 확인하고 시험용 관리자에서 운영 후기를 수정할 수 없게 합니다.
3. 운영 Worker와 `loan.climekr.com` 연결 및 TLS, 관리자 로그인, PC·모바일 상담 접수와 접수 결과, 후기 목록, 파기 일정과 장애 시 복구를 검증합니다. 기존 서비스와 DNS의 복구 방법을 준비한 뒤 연결을 전환합니다.
4. GitHub에서 Cloudflare로 안전하게 빌드·배포하도록 전용 권한을 설정하고, 저장소에 반영한 내용이 실제 Worker에 배포되는지 검증합니다. 참고: https://developers.cloudflare.com/workers/ci-cd/builds/api-reference/
5. 정기 백업과 복원, 키 복구, 오류 감시 및 파기 실패 알림을 완성합니다. Supabase 무료 프로젝트는 활동이 적으면 일시 중지될 수 있고 무료 요금제에서 내려받을 수 있는 자동 백업을 제공하지 않습니다. 운영 요구에 맞춰 별도 백업 또는 유료 요금제를 결정해야 합니다. 참고: https://supabase.com/docs/guides/platform/free-project-pausing 및 https://supabase.com/docs/guides/deployment/going-into-prod
6. 카카오톡과 채널톡은 사용자가 주소를 제공한 뒤 연결합니다. 현재 독립 관리자 화면에는 후기 CSV 일괄 등록 기능이 없습니다.

## 일상 관리

- 코드 수정은 비공개 저장소에서 검토하고 시험 환경에서 검사합니다. GitHub 자동 검사는 화면 파일 생성과 서버 기능 검사를 수행하며 실제 서비스 배포는 하지 않습니다. 직접 검사할 때는 `node independent/build.mjs`와 `node --test independent/tests/*.test.mjs`를 사용합니다.
- Cloudflare와 Supabase의 소유자 계정 및 인증 수단을 안전하게 관리합니다. ChatGPT 구독이 종료되어도 이 계정과 저장소를 통해 운영할 수 있도록 배포와 복구 절차를 완성해야 합니다.
- 연락 채널을 연결하기 전에는 상담 접수 후 운영자가 관리자 화면에서 접수 내역을 확인해야 합니다. 실제 대출 승인·금리는 상담 및 심사 결과에 따라 확인하며, 화면의 희망 조건과 월 상환액은 입력값에 따른 예시입니다.
