# 금융상담 플랫폼 독립 운영 안내

작성 기준: 2026-11-13 한국시간. 이 문서는 실제 전환과 검증 범위 및 남은 운영 항목을 기록합니다.

## 현재 구성

1. 고객 주소 `loan.climekr.com`은 2026-11-13 독립 운영 Worker `finance-counseling-production`의 Cloudflare 사용자 지정 도메인으로 전환됐습니다. DNS는 Cloudflare가 관리하는 프록시 레코드이며 기존 Sites 사용자 지정 도메인은 분리했습니다.
2. 소스는 비공개 GitHub 저장소 `goldeget/finance-counseling-platform`의 `main` 브랜치에 있습니다. Cloudflare Workers Builds가 시험 Worker, 운영 Worker, 기존 사이트 파기 Worker, 상담 백업 Worker에 연결되어 있습니다. 이 빌드들은 계정에 기존에 있던 `workflows-starter-template build token`을 공유하므로 그 토큰을 삭제하면 빌드가 중단됩니다. Supabase 후기 관리자 함수와 기존 Sites 본체의 배포는 이 GitHub 자동 배포에 포함되지 않습니다.
3. 독립 시험용 Worker와 운영 Worker가 따로 있습니다. 운영 관리자 주소는 `admin-loan.climekr.com`이며 운영 접수와 관리자 변경이 활성화되어 있습니다.
4. 상담 접수는 암호화하여 전용 Cloudflare D1에, 후기는 별도 Supabase 프로젝트 `finance-counseling-reviews`에 저장하는 구성입니다. 다른 유심 사이트의 저장소와 구분했습니다.
5. 관리자 접근은 Cloudflare Access의 이메일 일회용 인증과 서버의 서명 검증을 함께 사용합니다. 운영 주소에서 로그인 후 기존 접수와 전환 후 시험 접수를 확인했습니다. 후기 관리 함수는 운영용 Access 인증을 검증합니다. 운영 후기의 실제 등록·삭제는 전환 후 별도로 시험하지 않았습니다.

## 일상 관리

- 코드 수정은 비공개 저장소에서 검토하고 시험 환경에서 검사합니다. GitHub 자동 검사는 화면 파일 생성과 서버 기능 검사를 수행하며 실제 서비스 배포는 하지 않습니다. 직접 검사할 때는 `node independent/build.mjs`와 `node --test independent/tests/*.test.mjs`를 사용합니다.
- Cloudflare와 Supabase의 소유자 계정 및 인증 수단을 안전하게 관리합니다. ChatGPT 구독이 종료되어도 이 계정과 저장소를 통해 운영할 수 있도록 배포와 복구 절차를 완성해야 합니다.
- 연락 채널을 연결하기 전에는 상담 접수 후 운영자가 관리자 화면에서 접수 내역을 확인해야 합니다. 실제 대출 승인·금리는 상담 및 심사 결과에 따라 확인하며, 화면의 희망 조건과 월 상환액은 입력값에 따른 예시입니다.
